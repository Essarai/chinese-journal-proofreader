# Word 彩色修改与批注输出契约

默认交付独立、可编辑的 `<原文件名>_审校修改批注版.docx`。确定的错误直接改在正文；需作者决定或核证的文字保留原文并加 Word 原生批注。保留源文件、原有批注及未涉及的内容。用户明确要求仅批注或真正的 Word 修订记录时遵从其要求；字体着色本身不是可接受或拒绝的修订记录。

## 按处理状态着色

| 状态 | 字体色（RGB） | 适用范围 |
| --- | --- | --- |
| 已修改 | 蓝色 `0070C0` | 已直接落实的新增或替换文字；纯删除时以删除点紧邻的最短保留文字作定位标记 |
| 需作者修改 | 红色 `C00000` | 原意、施事、比较关系或论证方式须作者决定，编辑不能唯一改定的原问题文字 |
| 待核实 | 橙色 `ED7D31` | 事实、引文、版本、卷次、数量、页码等须查来源的原问题文字 |

颜色只表示处理状态，语法、错字、标点、论证、书目等问题类型写在批注里。若同一处既需查证又需作者改写，先以橙色标待核实，并在批注中说明核实后如何改写；避免两个状态覆盖同一字符。可选润色不强行着色，也不计入确定错误。只标最小可定位范围，不给整段或无关文字改色。旧有格式、主题色和未触及内容须保留。

## 细致语法审校

逐句阅读摘要、正文、表格说明、图注及可访问的脚注；长句先拆出各分句的主语、谓语、宾语、必要介词和中心语，再检查省略能否由上下文唯一补回。逐项检查句式杂糅、成分残缺、施事错位、动宾与修饰搭配、并列项是否同层级、比较双方是否同类、连接词与否定的作用范围、前后句指代。对相隔较远的主谓或共用谓语，逐项回读确认。引用原文、古籍异文、术语习惯和合理省略不机械判错；不能仅凭“读着不顺”添加批注。

确定错误且含义唯一时做最小修改；语义、事实或论证强度不确定时保留原文，让作者处理。每条语法批注须指出具体不成立的成分关系、读者可能误解什么、可操作的修改方向；不能只写“语句不通”。已修改的批注还要写原文、修改后文字与改动理由。跨句推断需查相关上下文，不能擅自增强论文结论。

## 台账、写入与批注

写入前记录文档部件、稳定段落或单元格位置、原文精确范围、原文、替换文本、操作、问题类型、处理状态、RGB、具体理由与修改后批注目标。同一位置候选先合并消歧，不全局替换。只有确认错误且替换内容可确定才直接修改；未核实的数字、史实、异文、出处不得猜改。

- 已修改：`【已修改｜语法·搭配不当】原文：……；修改后：……；原因：……。` 修改后新增或替换的最短文字标蓝，并在其上锚定批注。纯删除无法给被删字符着色，给删除点紧邻的最短保留文字标蓝作为定位，批注写明该蓝色文字是删除位置标记及完整被删原文。
- 需作者修改：`【需作者修改｜语法·主语不明】原文保留。问题：……；请作者明确……后修改。` 原问题最小片段标红并锚定批注。
- 待核实：`【待核实｜引文·页码】原文保留。问题：……；请核……来源与页码，核实后同步修改……。` 原问题最小片段标橙并锚定批注。

原有批注、回复、修订保留，不自动解决、删除、接受或拒绝。修改范围与原批注相交时保留其内容并可靠映射锚点；无法可靠映射或遇复杂字段时只加说明批注。保留段落样式、字体、字号、表格、图表、公式、字段、超链接及页眉页脚。按精确边界拆分 run 并继承其他属性；设置 RGB 时清除会覆盖它的主题色。仅加批注的工具不等于已改正文。

## 验收与交付

1. 源文件摘要不变；输出 ZIP、XML 与关系有效。所有可见文本和格式变化均能逐项对应台账，未列出的部件与内容保留。
2. 已修改文字为蓝色，需作者修改原文为红色，待核实原文为橙色；每条批注的状态、问题类型、内容、唯一 ID、范围和引用与台账一致。纯删除批注留存被删原文。
3. 检查原有批注和修订仍在。渲染并查看适用页面的文字、颜色、脚注、图表及换行；Word UI 可用时检查批注气泡与点击定位。结构、页面、Word UI 检查分别报告，不能互相代替。
4. 交付最终 DOCX，说明实际颜色图例、已修改数、需作者修改数、待核实数及未完成的检查；内部台账用于核验，不默认另交报告。
